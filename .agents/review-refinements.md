# Repo-local review refinements

### Pillar 1: Functional Correctness, Logic & Edge Cases
<!-- Loops append bullets here. -->
- **Rewind Claims Match State**: Overriding a rewind or checkpoint check on a backend with hidden recurrent state (short-conv, SSM): reporting Ok because the counters can move, while the device-side state cannot; refuse partial rewinds unless every stateful component is checkpointed, and verify by asserting the check errors for a stateful layer.
- **NaN Eviction Horizon Pinning**: Calculating a retention horizon by subtracting a duration from elapsed time (`covered - history_ms`): a non-finite, NaN, or non-positive value leaves floating point comparisons (`start_ms < horizon`) permanently false, preventing items from expiring and pinning buffers indefinitely; normalize duration to a valid positive default before subtraction, and verify with a test passing NaN that items still expire.
- **Zero Strided Scratch Every Call**: Skipping a padding re-zero behind a high-water mark when the consumer reads a padded stride: growth across an alignment boundary remaps previously written valid lanes into padding lanes, so the contraction reads stale data; zero the exact current box on every call (the memset is negligible next to the compute), and verify with a poisoned-buffer test that grows across the boundary and fails when the skip is restored.
- **Zero Divisibility Degeneracy**: Using modulo or divisibility checks (such as `dim.is_multiple_of(4)`) to gate kernel or hardware capability without explicitly asserting `dim > 0`: zero is divisible by every integer (`0 % 4 == 0`), so degenerate zero dimensions pass capability gates into optimized kernels where zero vectors cause divide-by-zero (`running_sum == 0.0` yielding `1.0 / 0.0 = inf`), infinite loops, or zero-stride buffer faults; guard dimensions with `dim > 0 && dim.is_multiple_of(...)` before dispatching, and verify with unit tests asserting zero dimension returns false.
- **Sibling Entry Point Capability Parity**: Hardening capability checks or dimension bounds on an internal or range-gated entry point while leaving the primary or default entry point with looser checks: callers using the default entry point bypass the new guards into optimized kernels where zero dimensions underflow unsigned index calculations; audit all entry points dispatching to the same underlying kernel and apply identical precondition guards to each.
- **Non-Zero WebGPU Buffer Allocations**: Sizing a WebGPU storage buffer dynamically from sequence lengths or dimensions using alignment padding (e.g. `len.next_multiple_of(32)`): empty inputs (`len == 0`) evaluate to 0 bytes, violating WebGPU's non-zero buffer requirement (`descriptor.size must not be 0`) and panicking the validation layer; clamp dynamic dimension allocations to at least one minimum workgroup tile or guard with an early return on empty inputs, and verify with an empty-input unit test.
- **Saturate Bounded Kernel Parameter Counts**: Packing bounded integer counts (such as worker thread or workgroup counts) into narrow bit-fields or byte fields in hardware or coprocessor parameter buffers with bit-shifts or masks (e.g. `(threads & 0xff)` or `(threads as u32) << 24`): out-of-contract counts (such as 256) wrap or truncate silently to zero in release builds (`256 & 0xff == 0`), dispatching illegal zero-thread requests that hang coprocessor firmware or cause division-by-zero crashes; saturate counts to the field's maximum representable value (e.g. `wire_byte` or `.min(255) as u8`) before bit-packing, and verify with tests passing out-of-contract counts (> 255) in both debug and release configurations.
- **Unpaired Delimiter Mentions Inside Enclosing Blocks**: Masking inner sections (such as `<tool_call>...</tool_call>`) before extracting an outer block (such as `<think>...</think>`): a bare or unclosed inner opener inside the outer block pairs with the closing tag of a real section after the outer block's closing delimiter or runs to the end of the text, swallowing the outer closing delimiter into the masked span; refuse to mask an inner opener across an outer closing delimiter when no inner body precedes it or when another inner opener follows the outer closing delimiter, and verify with tests mentioning bare `<tool_call>` markers inside `<think>...</think>` both before a real call and before plain prose.
- **Conjoin Freshness Flags With Existing Mode Guards**: Replacing an outer mode guard (such as `if !greedy || generated == 0`) with a newly introduced state-freshness flag (`if logits_fresh`) when tracking whether interleaved sub-steps left state valid: a sub-step that refreshes the value right before loop exit (such as an interleaved audio frame computing fresh logits at the end of a burst when `generated >= max_tokens`) causes the mode that previously cleared state (`greedy && generated > 0`) to retain it instead, breaking callers that assert cleared state after greedy turns; conjoin the freshness flag with the existing mode guard (`if (!greedy || generated == 0) && logits_fresh`) rather than substituting it, and verify both greedy and non-greedy post-call state invariants.
- **Interleaved Modality Inner-Loop Early Exits**: Breaking out of an inner audio loop on safety, context, token-cap, or cancel guards while `!text_done`: the break skips the audio-to-text forward pass so `logits` and `next_token` stay stale, and the outer loop's `continue` re-emits the old token; terminate the outer loop on every non-transition inner exit across `session.rs`, `audio_engine.rs`, and `cera-wasm`.
- **Non-Causal Prefill Single-Pass Invariants**: Routing a non-causal or prefix-LM model (`!config.is_causal`) through causal prefill optimizations (KV prefix caching, `ubatch_size` or `MAX_PREFILL_TOKENS` chunking, or per-segment multimodal append calls): prefix KV cells in bidirectional layers depend on suffix tokens, so restoring a prefix snapshot or splitting a prompt into `start_pos > 0` chunks breaks bidirectional visibility; gate prefix caching and chunking on `config.is_causal` and fuse multimodal rows into one pass, and verify warm cache stays empty after prefill.

### Pillar 2: Security, Authentication & Input Sanitization
<!-- Loops append bullets here. -->
- **Upfront Metadata Before Allocation**: Validating container metadata (GGUF, Safetensors) after or interleaved with tensor loading: malformed hyperparameters allocate hundreds of megabytes of weight memory before failing, and fail-fast header-only mock tests in CI cannot exercise the guards; validate all dimensions, strides, and runtime configurations upfront before reading or allocating tensors, and test with header-only mocks.
- **Upfront Head Dimension Accumulator Bounds**: A loader checking head divisibility (`tf_d % tf_heads == 0`) without bounding head dimension (`tf_d / tf_heads <= MAX_ACCUMULATOR_WIDTH`): valid-looking metadata loads hundreds of megabytes of weight tensors before tripping fixed stack-accumulator assertions during inference; validate head dimension upfront before weight allocations, and test with a metadata mock.

### Pillar 3: Concurrency, Asynchrony & Lifecycle Management
<!-- Loops append bullets here. -->
- **Refcount Process-Global Toggles**: Enabling a process-wide vote or mode (wakelock, QoS, power hint) per device or session: the first owner to drop cancels it for the rest, and a failed constructor leaks it; hold it in an RAII guard behind a global count (0 to 1 acquires, 1 to 0 releases), created before the first fallible step, and verify with a stub driver that logs acquire and release calls.
- **Recover Poison Consistently**: Fixing a poisoned-lock path in one function: sibling entry points that restage the same state still fail permanently, while recovering a lock over state that persists across calls (recurrent buffers, counters) continues over a torn pair; grep every lock site guarding the same resources, recover only state rewritten in full per call (log the recovery, drop any half-built pending work on entry), and reset persistent state explicitly on poison. A std `Mutex` stays poisoned after `into_inner()`: clear the flag (`clear_poison`) when recovering, or every later call repeats the reset and the warning; route all sites through one helper and unit-test that recovery reports once. For a lock guarding DSP-resident state that a panic can tear (the device lock), fail closed with an error until an explicit reset rewrites it, instead of recovering and continuing.
- **Pop After Success**: A tracked collection (rotation window, pending list) drained with `pop_front` before the fallible release step (unmap, free): a refusal leaves the resource held but untracked, so it is never retried and the budget leaks; peek, release, then pop, and verify with a fake that can refuse the call and a retry that succeeds.

### Pillar 4: Error Handling, Resilience & Diagnostics
<!-- Loops append bullets here. -->
- **Errors Not Silent Prefixes**: A multi-step operation whose earlier stage returns bare results (logs plus zeros): dropping that result and continuing over the gap yields plausible output computed over missing state; propagate the failed stage as an error, and verify with a fault-injecting test that the caller sees Err.
- **Recover Poison When Overwriting**: Resetting state behind a mutex with `if let Ok(guard)`: a poisoned lock skips the zeroing while counters still reset; recover with `into_inner` when the guarded state is fully overwritten.
- **No Silent Default Arms**: A `match (Option, Option)` whose `_ =>` arm quietly picks the common buffer or path: an inconsistent state (planned for paging, no pager) reads the wrong weights with no error; make every impossible combination a typed error, not a `debug_assert` or a fallback.
- **Warn Where Logcat Can See**: A new warning or an "active" notice in the Hexagon path emitted with `tracing::warn!` alone: `cera-ffi` installs no subscriber, so on a phone a partial pin or a typo'd knob is invisible; use `hexagon_warn!` (tracing plus stderr), including for a failure swallowed in `Drop`. Core modules outside the `hexagon` feature gate cannot name that macro: pair `tracing` with `eprintln!` directly there, following the `transformer.rs` fallback precedent, and verify by running the fallback with no subscriber and asserting the stderr line.
- **Preserve CI Failure Diagnostics**: Wrapping a test execution in CI with output truncation or swallow mechanisms (such as capturing into a variable with `|| true` and piping to `tail`): assertion failures and panic traces are stripped from logs and misclassified as filter or execution omissions; capture command output while preserving its exit code, print the full output on failure, and verify with a simulated assertion failure that failure diffs remain visible in logs.
- **Wrapper Download Retries Over Zero**: Setting retries=0 alongside a non-zero backoff duration in wrapper properties: downloader implementations cap attempts at one, disabling retry on transient network drops or socket timeouts and leaving backoff configuration inert; set retries=3 so automated runners survive intermittent distribution mirror glitches, and verify wrapper properties match expected retry counts.
- **Hoist Precondition Validation Ahead of Parameter Derivation**: Gating operand count, shape, or sentinel checks behind automatic parameter derivation branches (e.g. `if op.kernel_params == [0; 32]`): callers supplying precomputed kernel parameters bypass descriptor verification, dispatching unvalidated or sentinel indices (`0xffff`) directly to coprocessor hardware where they trigger out-of-bounds reads or firmware crashes; validate operand counts and sentinel invariants unconditionally before branching on parameter generation, and test both zeroed and precomputed configurations.

### Pillar 5: Interface Contracts, API Design & Compatibility
<!-- Loops append bullets here. -->
- **Idempotent Attach Setters**: A setter that also flips an unrelated opt-out flag (attach resets disable): callers that set the flag in config get it silently undone; keep each setter to its own field, and test the real construction path rather than assigning fields directly.
- **Propagate Mirrored Surfaces**: Editing a value mirrored across files (FFI doc text embedded in generated bindings, a version string repeated in manifests plus a VERSION file): a subset edit fails the drift or consistency job, while a core fix that never reaches the mirror leaves consumers coding against stale limits; propagate through the repo's own script or regen for every target (including the separately generated ones) in the same change (never hand-edit one site of a script-owned value), and verify with the drift or check command.
- **Plumb Opt-In Flags**: Renaming a constructor parameter to `_unused` while adding a new default: the config flag becomes dead and the experimental path turns on for everyone; keep the flag live end to end and test with a stub where support is true and the default is false.
- **Hermetic Knob Seams**: A new `CERA_*` env knob read straight from `std::env` in a constructor: a stray variable in the developer's shell flips the golden tests, and the parse rule drifts from the sibling knobs; give it a `from_lookup` seam, make the constructor ignore the environment under `cfg(test)`, parse opt-ins like the existing ones, warn on garbage, and document it in the env table; when the same knob is already read in several places, route every read through one shared parse helper with the same seam instead of adding another copy (copies drift: trim here, no trim there).
- **Multi-Model Mode Implication Conflicts**: Documenting that helper model flags imply a specific execution mode (e.g. transcript flags imply live mode): users passing conflicting modes or an incomplete subset of required models get silent fallbacks or overridden options; reject conflicting modes with an explicit error and require paired model dependencies atomically.
- **Producer Validates Consumer Contract**: A converter or export script omitting structural checks that the downstream engine strictly enforces: unsupported models succeed through minutes of conversion and quantization only to fail at load time; mirror consumer invariants in the producer script upfront to fail fast before long-running tasks.
- **Verify Regen Formatter Hooks**: Regenerating bindings when the generator shells out to a formatter (uniffi invoking ktlint): the hook can silently no-op locally and leave raw output that looks like a whole-file tool drift; run the formatter explicitly after regen, require the diff to be minimal (doc and checksum lines only), and confirm with the drift check.
- **Safe APIs Require Hard Assertions Over Debug Asserts**: Gating public precondition contracts (`pub fn`) with `debug_assert!` when dispatching to unsafe helper blocks: debug assertions are completely compiled away in release builds (`--release`), so invalid caller inputs bypass bounds checking and enter unsafe pointer arithmetic and fixed stack array indexing unverified; use explicit `assert!` for all public precondition contracts, and test that invalid inputs panic in both debug and release configurations.
- **Root Plugin Scope In Multi-Project Builds**: Declaring a plugin version alias in a subproject when a sibling plugin from the same artifact is loaded at the root level: parent classloaders load the shared classes without a version descriptor for the unapplied sibling, failing subproject resolution with an unknown-version conflict; declare alias(libs.plugins.<plugin>) apply false in the root buildscript so all subprojects inherit consistent classloader scopes and explicit version metadata, and verify clean configuration.
- **Shadow Module Transformer Duplicates Strategy**: Upgrading shadow packaging plugins with an active Kotlin module metadata transformer: the transformer merges duplicate module metadata files across dependencies, but default duplicate exclusion drops entries before the transformer executes, emitting packaging warnings; configure duplicatesStrategy = DuplicatesStrategy.INCLUDE on shadow tasks, and verify artifact assembly produces zero duplicate warnings.
- **Converter And Runtime Loader Round-Trip Parity**: Writing a GGUF converter module (such as mmproj or streaming HF conversion) and testing it only against its own metadata or tensor maps without loading the emitted GGUF through the runtime weight loaders (`VisionEncoderWeights::from_gguf`, `AudioEncoderWeights::from_gguf`, `AudioDecoderWeights::from_gguf`, `DetokenizerWeights::from_gguf`): metadata key or tensor name drift between converter and loader passes converter unit tests while failing every converted checkpoint at load time; verify every converter path with a round-trip test that serializes a synthetic checkpoint to GGUF bytes and loads it through the production runtime loader.
- **Sibling Multimodal Chat Entry Points**: Updating image or audio marker and boundary-token rules (`VisionProjectorType` dispatch for `Lfm2`, `Lfm3Vl`, and `Lfm3O`) in `Session::append_chat_with_images` (`cera/src/session.rs`) without updating the stateful `SessionChat` / `Chat` coordinator (`cera/src/session/chat.rs`, used by `Session::into_chat()` and `cera-ffi`): leaves `SessionChat` hardcoding legacy `<|image_start|>` and `<|image_end|>` boundary checks and rejecting or mis-wrapping `Lfm3Vl` and `Lfm3O` sessions; apply multimodal marker and boundary-token changes across both `Session` and `SessionChat`, and verify with unit tests on both entry points.
- **Continuation Turn Context For Deferred Schema Expansion**: Rendering continuation turns (`!initial`) through a template helper with an empty schema slice (`&[]`) to avoid re-emitting the initial system tool block: mid-conversation messages that reference registered schemas by name (such as `tool_reference` parts expanding into `<additional_tools>`) fail or leave raw JSON unexpanded, while passing the full schema table without `defer_loading` re-injects the system tool block on every turn; pass the registered schemas marked with `defer_loading: true` on continuation turns and serialize messages with typed content-part support, and verify that continuation `tool_reference` turns expand into `<additional_tools>` without re-emitting the initial tool list.
- **Unified Projector Filename Fallback In Pipeline Classification**: Widening `is_vision_mmproj` to match unified projectors (`mmproj-LFM3-Audio-*`, `mmproj-LFM3-Omni-*`) while gating `is_audio_pipeline` only on HF tags or `-audio-` in the repo slug: untagged repos or slugs ending in `-audio` or `-omni` populate `mmproj_ggufs` and fall through to `LlamaCppImageToText`; check repo slugs and primary/projector filenames before falling back to vision, and test untagged custom slugs.
- **Normalize Polymorphic Template Message Inputs**: Accepting generic serializable messages in a chat-template helper where some caller types encode structured content as a JSON string while others serialize a sequence or attach sibling fields (such as `additional_tools`): templates branching on string content emit raw JSON instead of expanding structured parts and ignore sibling fields; normalize stringified structured content and sibling fields into the canonical message representation before rendering, and verify with unit tests covering both message types.

### Pillar 6: Performance, Resource Efficiency & Scalability
<!-- Loops append bullets here. -->
- **Unaligned By-Value Descriptors**: Casting a byte buffer (align 1) to a struct reference to patch DSP or wire descriptors: relies on allocator alignment and is UB or a panic otherwise; read and write the descriptor by value with unaligned accessors behind a range check, and verify with a test that patches at a deliberately odd offset.
- **Derive Margins From Inputs**: A fit-or-page decision using a fixed slack for something sized later (KV cache by context length): a long context passes the check and then fails at allocation; compute the margin from the same inputs the later allocation uses.
- **Contiguous Attention Context Loop Inversion**: Evaluating attention context `ctx[i, dd] = sum_j scores[j] * v[j, dd]` with head dimension `dd` in the outer loop and timestep `j` in the inner loop: strides across memory by full embedding width `d` on every inner iteration, causing cache misses; invert the loop order to scan `j` contiguously in the outer loop while accumulating into a fixed-size stack buffer `acc[dd]`, achieving contiguous cache line access without altering summation order.
- **Disjoint Borrows Avoid Buffer Cloning**: Calling a helper on `&mut self` that only mutates specific fields while passing slices of sibling container buffers: cloning the slices to owned vectors (`.to_vec()`) merely to satisfy the borrow checker generates unnecessary heap churn in streaming loops; split the helper into a function borrowing only the mutated fields so caller slices can be passed directly without allocation.
- **Filter Raw Multimodal Mmaps Across All Engine Constructors**: Filtering only the parsed `vision_encoder` by inference type and `clip.has_vision_encoder` in `CeraEngine::from_gguf` while filtering the raw `vision_encoder_gguf` mmap only in `from_parts_with_primary`: path loads of audio-only bundles retain a duplicate `GgufFile` mmap; filter `vision_encoder_gguf` directly in both constructors and assert `vision_encoder_gguf().is_none()` on audio loads.

### Pillar 7: Code Simplification, Clean Architecture & Maintainability
<!-- Loops append bullets here. -->
- **Doc Comment Theft**: Inserting an item between a doc comment and its item, or a `use` under one: the doc silently reattaches to the wrong item, in every doc flavor (rustdoc, KDoc, JSDoc); after every insertion read the lines directly above each touched item and confirm the doc still describes that item.
- **Stale Limit Claims**: Lifting a limit with a new mechanism (paging past the DSP map ceiling): error strings, hints, doc comments and a docs bullet still say the old limit is absolute; grep the old claim everywhere and keep the message at the call site that still means it.
- **Estimates Assert Their Plan**: A second copy of a planning loop that feeds a decision (KV bytes for the paging choice): it drifts silently and zeroing it is caught by nothing; `debug_assert_eq!` it against the real plan's total after planning, and scope an error suffix ("these weights cannot run") to the call site that means it, not the shared allocator.
- **Hoisting Validation Ahead of Heavy Resource IO**: Validating CLI arguments or configuration parameters after loading model weights and decoding audio: invalid user inputs trigger disk I/O, linear resampling, and large tensor allocations before rejecting the command; hoist pure option constraints to function entry before loading resources.
- **Argparse Committed Script Paths**: Committing a helper script with a personal absolute path while its siblings take argparse flags: the script runs on one machine only and drifts from the directory shape; take every location as a flag with an expanded-home default behind the sibling `main()` guard, and verify with `--help` plus a compile.
- **Typed Variant Structs Over Field Punning**: Reusing legacy struct fields across model architectures by concatenating multiple tensors into a single `Vec<f32>` at hardcoded offsets or punning unrelated weight fields (`pos_bias_u` holding `q_norm_w`, `conv_in_proj` holding `attn_gate`): couples loader and forward pass to magic dimensions and breaks whenever a checkpoint uses a non-default projection width; introduce an optional architecture-specific struct (`Option<Lfm3FsqWeights>`, `Option<Lfm3aLayerExtras>`) with named fields and validate dimensions at load time.

### Pillar 8: Testing, Observability & Verification Invariants
<!-- Loops append bullets here. -->
- **Full Feature And Target Matrix Lints**: Running clippy or build checks only with combined host features: code gated on `--target wasm32-unknown-unknown` (`cera-wasm` `wgpu` paths) is skipped on host, and variables in `--features hexagon` tests only read inside `gpu` or `metal` cfg blocks fail CI's standalone `--features hexagon` lint; run `cargo clippy -p cera --features hexagon --all-targets -- -D warnings`, `cargo clippy -p cera-wasm --target wasm32-unknown-unknown --features wgpu -- -D warnings`, and `cargo build -p cera --tests --lib --target wasm32-unknown-unknown` before pushing.
- **Relative Error Ordering Needs Lossy Reference**: When asserting that a candidate output is closer to an exact reference than a baseline output (`cand_err < base_err`): substituting a lossless or unquantized model fixture reduces the baseline error to zero, breaking the inequality assertion even though candidate accuracy is within specification; assert against absolute numerical error thresholds or guard relative error comparisons by verifying the baseline fixture exhibits the expected quantization loss.
- **Mirror Tests Are Vacuous**: A test that re-implements the production formula or patch loop inline and asserts its own copy passes when production drifts; extract the logic into a function the production path calls and test that, and prove non-vacuity by mutating production in a scratch copy.
- **Throttles Vacate No-Op Tests**: Adding a rate limiter or cache in front of an entry point: a test asserting the no-op result passes without running the checked logic when another test consumed the window; test the unthrottled core directly and unit-test the limiter with an injected clock.
- **Untested Fix Is Unfixed**: Fixing a defect in code needing a device or driver: the fix regresses silently; extract the pure decision (counter, chunk split, validation) so a host test can pin it, and mutate production once to prove the test fails.
- **Fakes Must Be Able To Refuse**: A fix that depends on call order or a refusal (release before unmap, munmap error 1): a fake driver that always succeeds, answers every buffer with one fd and ignores arguments cannot fail the test; give each call the fix depends on a refusal knob and an event with its fd, assert the order, and mutate production once to see the test fail.
- **Exercising Dual Return Signatures**: Adding a richer return variant (`finish_with_frames`) while existing integration suites only call the default wrapper (`finish`): the added vector and its formatting remain untested in realistic end-to-end flows; update end-to-end tests to exercise the dual return and assert buffer invariants on the auxiliary output.
- **Probe Logic Lives In The Lib**: Probe-critical parsing or framing kept in `cera/examples/*`: no CI leg passes `--examples`, so the code runs only on a device bench and regressions stay green; move it into the `cera` lib with unit tests and let the probe call it, and verify the tests run in the default workspace leg.
- **Zero Tests Ran Is Not Green**: Verifying with a package-scoped run (`cargo test -p`) when test files are feature-gated: the file compiles to zero tests and reports ok, which reads as a pass while the real gate (workspace feature unification) runs them and fails; always verify with the repo's own gate command, and treat any `0 tests ran` line as an unverified scope gap, never as a pass.
- **Gate Helpers Like Their Callers**: A test helper marked plain `#[cfg(test)]` whose only callers live behind a narrower feature gate: compiling that feature off leaves the helper uncalled and the no-default warnings-as-errors legs fail on dead code; give the helper the same `cfg` conjunction as its callers, and verify by building the feature-off matrix legs.
- **Tick Private Doc Links**: A rustdoc comment on new public API using intra-doc links (`[...]`) to private or feature-gated helpers: the strict doc lint (`-D warnings`) fails on the unresolvable link when building default features or when the feature gate is inactive; reference private or feature-gated items with plain code ticks instead, and verify with the repo's doc lint command.
- **Suspect Merge-Commit Drift First**: A test failing on CI while passing locally, with a different test total than the local run: the PR leg builds the merge with main, so a landed refactor (changed helper output, new tests) breaks branch-pinned expectations that the tip alone cannot reproduce; diff the branch against its merge-base before any environment theory, merge main and mirror the landed update, and verify the local total matches CI's.
- **Portable Knob Testing**: Placing environment-variable parsing helpers behind architecture target gates (such as `#[cfg(target_arch = "aarch64")]`): non-matching test runners and CI architectures cannot execute or pin the parsing logic; cfg-gate pure helpers on `#[cfg(any(target_arch = "...", test))]` so all test targets can test the logic portably.
- **ELF Header Checks Complement Filename Pins**: Pinning vendored shared libraries by filename lists and exports across bindings and host wrappers: cloning or repacking architecture variants without patching internal ELF metadata leaves `DT_SONAME` unchanged, causing dynamic linkers or DSP runtime loaders to treat distinct binary variants as identical; verify internal ELF `SONAME` headers match file basenames directly in CI verification scripts, and test with candidate binaries.
- **Recording Sinks Share Queue Enqueue Derivation**: Adding operand validation and `kernel_params` derivation inside `HexagonQueueSession::enqueue_op` while leaving `RecordingSink::enqueue_op` as a raw push or a duplicate copy: unit tests driving `dispatch::*` helpers through `RecordingSink` accept invalid shapes or drift from the real queue's checks; extract a single shared helper (`validate_and_derive_op_params`) called by both `HexagonQueueSession::enqueue_op` and `RecordingSink::enqueue_op`, and verify with unit tests on `RecordingSink`.
