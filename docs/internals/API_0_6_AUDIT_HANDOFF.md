## Implementation and decisions

- Native Session checkpoint/restore explicitly reject models retaining a backend session lease. Built-in Metal/wgpu state lives on the model; a host-only checkpoint cannot represent it. This is explicit rejection, not new GPU checkpoint support. Spy tests prove rejection preserves session/device position; no native GPU checkpoint parity claim.
- Restore validates exact attention K/V geometry, recurrent buffer sizes, vocabulary-sized logits, and compression/seed identity before mutation. A compatible default `Model::validate_checkpoint_state` hook permits Bailing/Ling MLA's unequal key/value widths. Actual tiny Bailing f32/f16 tests restore and continue correctly, including when KDA scratch dimensions exceed MLA widths. Malformed rows are rejected before mutation.
- WebGPU import/export shares compression cache tags and row validation; fallback allocations use effective uncompressed settings. Pure Node validator tests cover seed and malformed geometry without a physical GPU.
- Old f16/TurboQuant fingerprints are rejected; f32 fingerprints are unchanged. Fingerprints establish structural compatibility, not cryptographic model identity.
- Chat installs the profile terminal as a stop token and the grammar mask permits per-call stop tokens once output is complete. Split UTF-8 fragments are buffered. Replacement ingestion counts from the reset baseline. Typed loading admits supported generative architecture families.
- Successful native Session transfer disables old-handle cancellation controls. Moved Chat terminal callbacks run after releasing its mutex. Invalid JSON schema emits exactly one terminal error on sync/async streaming paths. Operations already racing transfer retain normal atomic ordering; explicit cancellation handles keep their existing semantics.
- Kotlin closes its Flow only after the native future returns; abandonment explicitly calls the Chat receiver's cancellation method. Python also waits for native return, and closing a completed worker no longer cancels the next operation.
- Python helpers live in `cera_ffi_streaming.py`; the actual generated module installs them. `scripts/patch-python-bindings.py` runs in `just bindings` so regeneration preserves this entry point. Package imports reexport the same helpers.
- WASM Chat callbacks return a plain error after unwinding normally. Arbitrary thrown JS values are never formatted on the Rust borrow path; cyclic arrays and throwing getters are covered for ordinary and JSON streaming. This covers ordinary thrown values, not recursive access to the same Chat handle: re-entry, including cancellation or property reads from its callback, is unsupported and can leave the handle unusable. Raw CPU Session has the same re-entry restriction and lacks Chat's ordinary callback-error recovery. Removed the old unsafe raw callback cancellation recipes and aligned Rustdoc; no new CPU cancellation mechanism is implemented. Browser WebGPU has a separate cancellation handle.
- JSON grammar enforces required keys despite optional siblings, emits keys once in the compiler's fixed map order, supports array bounds up to 1024 through nested bounded repetition, and gives refs distinct JSON-pointer identities. Unsupported intersections and direct `$ref` sibling constraints are rejected; supported object-property/required merges inside `allOf` are an exception. This remains a documented subset of JSON Schema; general unimplemented validation keywords are not enforced, and enum/const/union dispatch does not combine sibling type/object/array constraints.
- Flutter chooses ChatML/Llama/Gemma continuation delimiters from its rendered user header; unknown formats get a visible request to start a new chat before native state changes.
- Audio processing stops at KWS hop/VAD window boundaries, consumes wake-detection suffixes immediately, bounds retained PCM, and translates detector epochs into the global sample clock. Natural ends preserve VAD continuity; duration continuations preserve detector state. Returning to wake listening clears noncontiguous KWS history while preserving unexpired cooldown across the speech interval. Explicit builder/iterator hotword configuration wins over pipeline defaults.
- Swift/Python/Dart/Kotlin examples handle max-token Interrupted results before attempting a second user turn. Interrupted Chat requires reset or replacement; each example reclaims Session and exits on that path. Dart/Kotlin corrections were added after live binding validation; their real-model runs exit successfully at position 104 with assertions/checks active.
- Version 0.6.2 is propagated through VERSION, Cargo workspace/internal pins, Cargo.lock, Dart/plugin/Maven/platform manifests, CeraChat's dependency pin, current display labels and both package changelogs. Historical release notes and release-managed Apple binary checksums remain historical; no 0.6.2 tag or release exists from this work.
